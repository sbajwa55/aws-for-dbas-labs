# AWS for Database Administrators — Lab Files

Companion code for the book *AWS for Database Administrators* by Sandeep S. Bajwa
([Bajwa Consulting Services](https://bajwaconsulting.com)).

> ⚠️ These labs are for practice only. Do not run them against production systems.

## Labs
| Lab | Folder | Topic |
|-----|--------|-------|
| 1 | [`lab1-oracle-to-oracle-on-amazon-ec2`](lab1-oracle-to-oracle-on-amazon-ec2) | Oracle to Oracle on Amazon EC2 |
| 2 | [`lab2-oracle-to-mysql-on-amazon-rds`](lab2-oracle-to-mysql-on-amazon-rds) | Oracle to MySQL on Amazon RDS |
| 3 | [`lab3-mysql-to-oracle-on-ec2-and-postgresql-on-rds`](lab3-mysql-to-oracle-on-ec2-and-postgresql-on-rds) | MySQL to Oracle on EC2 and PostgreSQL on RDS |
| 4 | [`lab4-postgresql-to-oracle-on-amazon-ec2`](lab4-postgresql-to-oracle-on-amazon-ec2) | PostgreSQL to Oracle on Amazon EC2 |
| 5 | [`lab5-oracle-goldengate-to-aws`](lab5-oracle-goldengate-to-aws) | Oracle GoldenGate to AWS |

Each lab is independent. Scripts are numbered in the order the book uses them
(`01-step0.1-…`, `02-step0.2-…`), and each lab ends with cleanup scripts that remove
all chargeable AWS resources.

Host names (`*.bcs.com`) and `192.168.55.x` addresses are examples. Replace them with your own.
